# Parcial II - Programación II (G412)

Simulador de batallas entre criaturas utilizando polimorfismo, herencia y clases abstractas en Java.

## 🛠️ Estructura del Proyecto
* `Criatura.java`: Clase abstracta base que define los atributos y métodos abstractos del sistema.
* `Dragon.java`, `Mago.java`, `Guerrero.java`: Subclases concretas con comportamientos de ataque y defensa únicos.
* `Main.java`: Clase principal que ejecuta la simulación de batalla entre criaturas.
* `CriaturaTest.java`: Pruebas unitarias para validar la lógica del combate y estado de las criaturas.
